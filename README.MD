# Практична робота №4
Тема: Розробка мультипоточних додатків з використанням синхронізації для управління конкуренцією в Python.
Виконав студент групи БІКСб12540, Смоляков В.І.

## Опис файлів
* `t1.1.py` — паралельне виконання I/O-bound задач у потоках (`threading`), демон-потік `MonitorThread` та `threading.Event`.
* `t1.2.py` — паралельне обчислення простих чисел через `multiprocessing.Pool` (`starmap`) із виводом PID процесів.
* `t2.1.py` — демонстрація гонки даних (race condition) на банківському рахунку та її усунення через `threading.Lock`.
* `t2.2.py` — пул з'єднань із обмеженням доступу через `threading.Semaphore`, координованим стартом `Event` і захистом лічильників.
* `t3.1.py` — бенчмарки `ThreadPoolExecutor` (I/O-bound) і `ProcessPoolExecutor` (CPU-bound) та обробка виключень через `as_completed()`.
* `t3.2.py` — паттерн Producer-Consumer із `queue.Queue`, виявлення дедлоку за таймаутом та його усунення.
